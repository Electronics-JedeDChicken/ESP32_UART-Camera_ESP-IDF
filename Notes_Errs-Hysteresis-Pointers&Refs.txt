Pointers- stores adr not val, since copying large obj's is expensive (e.g. large array/dstruct?)
int x = 10;
int* ptr = &x;  // ptr now stores addr of x, dtype matters...
*& (Address-of operator), * (Deref operator)
*ptr = 99;  // x becomes 99
ptr = nullptr  // Now points to nothing, always check before dereferencing else crash / undefined behavior

Refs as Params

Hysteresis
*E.g. you have 4 zones- 0-99 (1), 100-199, 200-299, 300-399 (4)
*Instead of just checking if value read's w/in zone...
*Since (analog) stuff have noise & if you ideally read 100- it actually "fluctuates" like 100-98-101-100
*So you'll unintentionally jump zones- 2-1-2-2
*So use hysteresis by expanding range that overlaps w/ other zones, but if you're currently in a zone is you won't jump immediately
*E.g. you're in zone 2, range then becomes like 95-204... (allowance...)
